About NoteGuard

An image-based Philippine peso banknote authenticity screening tool powered by classical machine learning.

How It Works

From image upload to authenticity verdict — a 4-step pipeline

1

Upload

You photograph or upload an image of a Philippine peso banknote. The app accepts PNG, JPG, GIF, BMP, and WebP formats up to 16 MB.

2

Feature Extraction

The image is converted to grayscale and resized. A Discrete Wavelet Transform (Haar / db1) is applied, and statistical features — variance, skewness, kurtosis, and entropy — are computed from the approximation coefficients. Color channel means and standard deviations (R, G, B) are also extracted, giving a 10-dimensional feature vector.

3

Classification

The feature vector is fed into a trained Random Forest or Decision Tree classifier (scikit-learn). The model compares the features against patterns learned from 868 Philippine banknote images.

4

Result

The model returns a verdict — Genuine, Forged, or Suspicious — along with a confidence score. An out-of-distribution check flags images that fall outside the training data range.

Features Extracted
  • Images sourced from Roboflow YOLO dataset crops of Philippine banknotes and realistic counterfeit simulations.
  • Features extracted using PyWavelets (Discrete Wavelet Transform) and OpenCV color analysis.
  • Balanced dataset (50/50 genuine/forged) split 80/20 for training/testing with GroupShuffleSplit to prevent data leakage from augmented crops of the same source image.

Important Disclaimer

  • NoteGuard is an educational project and proof-of-concept. It is NOT a certified counterfeit detection system.
  • Image-based screening cannot replace physical inspection of security features (FEEL, LOOK, TILT) as recommended by the Bangko Sentral ng Pilipinas.
  • Always verify suspicious banknotes through official BSP channels: (02) 8708-7087 or bsp.gov.ph
